# I20-23 Resource Library — Book List (Real Drive Links, Mapped to Catalog Units)

**Source:** every file below was found live in the `Books/` folder of the connected Google Drive
(owner: `lumenacademyforyou@gmail.com`) via `search_files`/`get_file_metadata`. No links, file IDs, or chapter
titles are invented — every title was read from the PDF's own extracted text.

**Edition:** these are the **2026-27 reprint of NCERT's post-2023 "Rationalised" textbooks** (confirmed from
the reprint/edition text inside the PDFs). The rationalised edition dropped or merged several older chapters
(States of Matter, Surface Chemistry, p-Block Elements, Solid State, Hydrogen, s-Block, Environmental
Chemistry) and renumbered what's left, so a handful of real chapters currently have **no clean home** in the
live 38-unit catalog — see **Gaps found** at the end instead of a forced mapping.

**Link format:** `https://drive.google.com/file/d/<fileId>/preview` throughout, per the pasted best-practice
(never `/view` — no forced download, streams cleanly in the `WebView`, zero extra storage since it's
Drive-hosted).

**Catalog reference:** unit ids/names are the live 38 `catalog.syllabus_node` units from
`database_sample/syllabusData.ts` (10 Physics, 10 Chemistry, 9 Botany, 9 Zoology). A chapter can legitimately
support more than one unit — where that happens it's simply listed under both.

`unit_code` maps to the `unit_code` FK the pasted `BookViewerScreen` best-practices ask for; `book_id` should
be the Drive `fileId` (or a DB row keyed to it) — not invented here since that's a CL-7 schema decision.
